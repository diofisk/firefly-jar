# Firefly Jar

A small browser game: catch fireflies in a dark meadow before dawn. Dim fireflies are worth 1 point, bright ones 3, but they fly faster. One night lasts 60 seconds, and the best score is kept.

Play: open `index.html` in a browser. No build step, no dependencies.

## Files
- `index.html`: the page, the score line and the start screen.
- `game.js`: the game loop, the fireflies, catching, the night timer, the best score.
- `style.css`: the look.

## Notes
- Who it is for: people who want a two-minute game on a break, on desktop.
- What players say: it is pretty and relaxing, but after one or two nights they close the tab. Nothing pulls them into another round.
- What must stay: calm, no violence, no ads, one screen.
